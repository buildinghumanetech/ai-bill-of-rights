### Summary of changes since last update
Added a CC BY 4.0 licence grant to the public "propose a new right" flow (/propose), shown directly above the submit button, and recorded it per submission on `proposed_edits` via a new hand-applied migration `drizzle/0012_proposal_license.sql`. Before this, proposals were accepted with no licence, so their text could not lawfully be republished in a version of the document.

### Detail of changes made:
- `src/lib/proposals/license.ts` — single source for the licence (`PROPOSAL_LICENSE`: id `CC-BY-4.0`, name, short name, URL) and the form field name.
- `src/components/ProposeRightForm.tsx` — always-visible notice above "File this proposal": "By submitting, you agree to license your proposed text under Creative Commons Attribution 4.0 International (CC BY 4.0), which allows it to be published and reused with credit to you." CC BY 4.0 links to the CC deed. The form posts `license=CC-BY-4.0`.
- `src/server/proposals/core.ts` — `createNewArticleProposal` now requires `license === PROPOSAL_LICENSE.id` (refuses otherwise, asking for a reload) and writes `license` + `license_granted_at = now()`. The refusal stops a stale tab or a direct POST from being stamped with terms its author never saw.
- `src/server/actions/proposals.ts` — passes the form's licence field through.
- `src/lib/db/schema.ts` / `drizzle/0012_proposal_license.sql` — two nullable columns, `license text` and `license_granted_at timestamptz`. **No default and no backfill on purpose**: an ADD COLUMN with a DEFAULT backfills every existing row in Postgres, which would record a grant nobody gave. NULL means no grant was recorded.
- `src/lib/db/proposal-queries.ts` — `ProposedRight` exposes `license` / `licenseGrantedAt`.
- `src/app/admin/proposals/page.tsx` — each row shows "Licensed CC-BY-4.0 · granted <date>", or an amber warning when there is no grant ("Get the author's permission before publishing this text").
- `src/lib/github/mirror-proposal.ts` — the optional GitHub issue mirror states the licence.
- `scripts/count-unlicensed-proposals.ts` — READ-ONLY count of ungranted proposals by kind/status/author. Works before or after 0012.
- README post-deploy list — 0012 added, flagged as apply-BEFORE-deploy.
- Tests: `tests/server/proposals.test.ts` (records grant, refuses a missing or wrong id, exposes null for old rows), `tests/server/proposal-license-migration.test.ts` (migration leaves pre-existing rows NULL, re-runs cleanly, has no default), `tests/components/propose-right-form.license.test.tsx` (notice visible inside the form, not in a `<details>`, link href, and the FormData carries the id).
